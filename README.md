# fetchhead

Fetch timestamps and head durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/fetchhead/

## Install / run

```bash
git clone https://github.com/theworker02/fetchhead.git
cd fetchhead
node src/cli.js
node --test
```
